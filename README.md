# Mobile Computing — ITA0330

This repository contains the ITA0330 Mobile Computing coursework, course
outcome assignments, and laboratory experiment reports and design links.

## Repository layout

| Folder | Contents |
| --- | --- |
| [`Assignments/`](Assignments/) | CO1–CO5 assignment submissions |
| [`Lab_Exp/`](Lab_Exp/) | Mobile computing laboratory experiment reports and Figma links |

## Assignments

Each assignment folder contains the submitted PDF report for that course
outcome. See [`Assignments/README.md`](Assignments/README.md) for the index.

## Laboratory experiments

The [`Lab_Exp/`](Lab_Exp/) folder contains experiments 1–14 as PDF reports and
provides links to the associated Figma designs in its README.

## Notes

The PDF files are submitted coursework artifacts. The files named `a` in CO4
and CO5 are empty or placeholder files and are retained as originally uploaded.
