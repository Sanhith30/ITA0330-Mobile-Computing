<div align="center">

### *An Explainable Mobile Computing Security Framework & Intelligent Wi-Fi Trust Assessment System*

* **Team**: T. Sanhith (192311228), P. Veeraswami (192311253), P. Jawed Khan (192311263)
* **Core Problem**: Protects mobile users against **Evil Twin attacks**, **rogue access points**, **SSID spoofing**, and **phishing captive portals** by auditing trust *before* association.
* **Key Innovations**:
  * **4-Tier MCDA Engine**: Calculates normalized trust scores (0–100) combining Encryption (40%), SSID Similarity (30%), OUI Hardware Vendor (20%), and RSSI Signal (10%).
  * **Levenshtein Distance Spoofing Guard**: Catches character-similar rogue access points ($D \le 2$) with cipher mismatches.
  * **RFC 6585 Gateway Probe**: Probes `http://connectivitycheck.gstatic.com/generate_204` to verify direct routing vs captive portal hijacking.
  * **Spectrum Analyzer**: Renders parabolic channel curves across 2.4 GHz and 5 GHz bands to identify interference.
